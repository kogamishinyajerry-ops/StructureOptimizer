# StructureOptimizer

StructureOptimizer is a local-first structural optimization MVP. It runs small 2D/2.5D SIMP benchmark models through baseline finite element analysis, topology optimization, independent verification checks, and static demo/report generation.

This project is an engineering demo and research workbench. It generates optimization candidates, not production-certified parts.

## Requirements

- Python 3.11 or newer
- NumPy
- pytest for tests

The current MVP intentionally avoids CAD kernels, GUI frameworks, web servers, commercial solvers, cloud services, and frontend build tooling.

## Quickstart

Run the test suite:

```bash
python -m pytest
```

Run the smoke benchmark:

```bash
python -m structure_optimizer run --benchmark mbb_beam --preset smoke
```

Verify an existing run:

```bash
python -m structure_optimizer verify --run runs/mbb_beam/<run_id>
```

Regenerate the Markdown report:

```bash
python -m structure_optimizer report --run runs/mbb_beam/<run_id>
```

Generate a static engineering demo package:

```bash
python -m structure_optimizer demo --benchmark simple_bracket --preset demo
```

The demo command prints the generated `demo.html` path. Open that file directly from disk to view the demo.

Run the local candidate study:

```bash
python -m structure_optimizer study --config studies/simple_bracket_tradeoff.json
```

The study command prints `runs/studies/<study_id>/study.html`. Open it from disk to compare ranked candidate runs, density thumbnails, verification status, and raw artifacts.

## Output Files

Each run creates a directory under `runs/<benchmark>/<run_id>/` containing:

- `input.json`: resolved benchmark configuration
- `metrics.csv`: per-iteration optimization metrics
- `baseline.png`: baseline design domain visualization
- `loadcase.png`: load and constraint visualization
- `optimization_frames/`: selected density evolution frame PNGs
- `optimization.gif`: animated density evolution
- `density.npy`: final density field
- `density.png`: final density visualization
- `convergence.png`: compliance convergence visualization
- `verification.json`: independent verification result
- `manufacturability.json`: coarse v0.2 manufacturability warnings
- `report.md`: engineering run report
- `demo.html`: static demo page when generated by the demo command

`verification.json` includes the objective, response metrics, constraint statuses, per-load-case metrics when configured, and manufacturability warnings.

Each study creates a directory under `runs/studies/<study_id>/` containing:

- `study_input.json`: resolved study configuration
- `candidates.csv`: ranked candidate metrics and parameter values
- `study.html`: static Chinese candidate comparison page
- `candidate_###/`: normal run artifacts for each parameter combination

## Current Benchmarks

- `mbb_beam`
- `cantilever`
- `l_bracket`
- `loaded_hook`
- `simple_bracket`

`simple_bracket` includes a `demo` preset intended for the static HTML demo workflow. It also exercises v0.3 engineering semantics: frozen solid regions, a void/keep-out region, and two weighted load cases.

## Known Limitations

- The FEM implementation is dense NumPy and intended for small benchmark meshes.
- The MVP uses linear-elastic 2D/2.5D models only.
- It does not support CAD import/export, STEP/NURBS reconstruction, full 3D FEM, nonlinear contact, fatigue, buckling, composites, or multiphysics.
- Engineering regions are currently structured-grid selectors only, not CAD topology selections.
- Manufacturability checks are coarse warnings for isolated islands, thin-member candidates, and unresolved local density regions.
- Study support is a local grid search over explicit parameter lists; it is not OpenMDAO, Dakota, or a general optimizer.
- Results must be treated as optimization candidates requiring engineering review, high-fidelity validation, manufacturability review, and physical testing before production use.
